# 要件定義書 — Stylish MyCars

> プロジェクト: Stylish MyCars（車両管理アプリ）
> プラットフォーム: Android（minSdk 26 / targetSdk 36）
> 作成日: 2026-07-20
> ステータス: ドラフト

---

## 1. 概要

### 1.1 アプリの目的

自家用車の維持管理に必要な情報（車検・保険・税金の期限、メンテナンス履歴、給油・費用の記録）を一元管理し、期限の通知やコストの可視化によって、車の維持にかかる手間と不安を軽減する。

### 1.2 解決する課題

| # | 課題 | 現状 |
|---|------|------|
| P1 | 車検・自賠責・自動車税の期限を忘れる | 紙の書類やカレンダーで管理。リマインダーがない |
| P2 | 整備記録が散在する | 紙の整備記録簿、レシート、メールがバラバラ |
| P3 | 年間維持費が把握できない | 何にいくら使っているか見えない |
| P4 | 燃費の推移が追えない | 給油しても記録しない、続かない |
| P5 | 日本制度に対応した管理アプリがない | 海外アプリは車検・自賠責・税金に非対応 |

### 1.3 ターゲットユーザー

| ペルソナ | 説明 | 優先度 |
|---------|------|--------|
| 車を1台持つ一般ユーザー | 車検・税金の期限管理と最低限の記録がしたい | **メインターゲット** |
| 複数台所有する車好き | 車両ごとの詳細な整備履歴・費用を管理したい | セカンダリ |
| 家族で車を共有する世帯 | 家族で記録を共有・閲覧したい | 将来対応 |
| 車を資産として管理したい人 | TCO（総所有コスト）の把握、売却判断材料が欲しい | 将来対応 |

## 2. 機能要件

### 2.1 MVP（Phase 1）— 必須機能

#### FR-01: 車両情報の登録・管理

| ID | 要件 | 優先度 |
|----|------|--------|
| FR-01-01 | 車両を登録できる（メーカー、車種、グレード、年式、型式、ナンバー） | P0 |
| FR-01-02 | 初度登録年月を登録できる（車検満了日の自動計算に使用） | P0 |
| FR-01-03 | 排気量・車両重量を登録できる（税金計算に使用） | P0 |
| FR-01-04 | 複数台の車両を登録・切り替えできる | P0 |
| FR-01-05 | 車両情報を編集・削除できる | P0 |
| FR-01-06 | 車両の写真を登録できる | P1 |

#### FR-02: 車検・保険・税金の期限管理

| ID | 要件 | 優先度 |
|----|------|--------|
| FR-02-01 | 初度登録年月から車検満了日を自動計算する（初回3年、以降2年） | P0 |
| FR-02-02 | 自賠責保険の満期日を管理する | P0 |
| FR-02-03 | 任意保険の満期日・保険会社・等級を管理する | P1 |
| FR-02-04 | 自動車税（種別割）の税額を排気量から自動計算する | P0 |
| FR-02-05 | 自動車重量税の税額を車両重量から自動計算する | P1 |
| FR-02-06 | 期限が近づいたら通知する（段階的: 3ヶ月前、1ヶ月前、2週間前） | P0 |
| FR-02-07 | 税金の納付済みフラグを管理する | P1 |

#### FR-03: 給油記録・燃費管理

| ID | 要件 | 優先度 |
|----|------|--------|
| FR-03-01 | 給油を記録できる（日付、給油量、金額、走行距離） | P0 |
| FR-03-02 | 満タン法で燃費を自動計算する | P0 |
| FR-03-03 | 燃費の推移をグラフで表示する | P1 |
| FR-03-04 | 前回の給油記録をプリセットして入力を簡素化する | P0 |

#### FR-04: メンテナンス記録

| ID | 要件 | 優先度 |
|----|------|--------|
| FR-04-01 | 整備を記録できる（日付、項目、費用、走行距離、メモ） | P0 |
| FR-04-02 | 法定12ヶ月・24ヶ月点検のチェックリストで記録できる | P1 |
| FR-04-03 | 整備項目のテンプレートから選択できる（オイル交換、タイヤ交換等） | P0 |
| FR-04-04 | 整備履歴を時系列で表示する | P0 |

#### FR-05: 費用管理

| ID | 要件 | 優先度 |
|----|------|--------|
| FR-05-01 | 費用をカテゴリ別に記録できる（燃料、整備、保険、税金、その他） | P0 |
| FR-05-02 | 月次・年次の費用集計を表示する | P1 |
| FR-05-03 | 1kmあたりのコストを計算する | P2 |

#### FR-06: データ管理

| ID | 要件 | 優先度 |
|----|------|--------|
| FR-06-01 | 全データを端末内（Room DB）に保存する（オフラインファースト） | P0 |
| FR-06-02 | データをJSON/CSVでエクスポートできる | P1 |
| FR-06-03 | エクスポートしたデータをインポートできる | P2 |

## 3. 非機能要件

### 3.1 性能

| ID | 要件 |
|----|------|
| NFR-01 | アプリ起動から画面表示まで2秒以内 |
| NFR-02 | 給油記録の入力から保存まで3秒以内（クイック入力時） |
| NFR-03 | 車両10台、給油記録1000件、整備記録500件で快適に動作する |

### 3.2 可用性

| ID | 要件 |
|----|------|
| NFR-04 | 全機能がオフラインで動作する（ネットワーク不要） |
| NFR-05 | 通知はAndroidのDozeモード下でも確実に配信する |
| NFR-06 | 画面回転・設定変更でデータが消失しない |

### 3.3 セキュリティ・プライバシー

| ID | 要件 |
|----|------|
| NFR-07 | 位置情報は取得しない |
| NFR-08 | 車両情報（ナンバー、車台番号）は暗号化して保存する |
| NFR-09 | 広告は表示しない |
| NFR-10 | ユーザーの同意なくデータを外部送信しない |

### 3.4 保守性・拡張性

| ID | 要件 |
|----|------|
| NFR-11 | Clean Architectureに準拠し、層間の依存方向を制御する |
| NFR-12 | Domain層はAndroid SDKに依存しない（JVMテスト可能） |
| NFR-13 | データソースの差し替えがRepository層のみで完結する |

### 3.5 対応環境

| 項目 | 値 |
|------|-----|
| minSdk | 26（Android 8.0） |
| targetSdk | 36 |
| 言語 | Kotlin |
| UI | Jetpack Compose + Material 3 |
| DI | Koin 4.0 |
| DB | Room 2.7 |
| ナビゲーション | Navigation3 |

## 4. 画面構成（MVP）

```
AppNavigation
├── VehicleListScreen          ← 車両一覧（ダッシュボード）
│   ├── 車両カード（期限が近い項目を強調表示）
│   ├── 車両追加ボタン（FAB）
│   └── 車両切替
├── VehicleDetailScreen        ← 車両詳細
│   ├── 車両情報セクション
│   ├── 期限管理セクション（車検・自賠責・保険・税金）
│   ├── 最近の記録（給油・整備）
│   └── 費用サマリー
├── FuelRecordScreen           ← 給油記録一覧・入力
│   ├── 給油記録リスト
│   ├── 給油入力ダイアログ
│   └── 燃費推移グラフ
├── MaintenanceRecordScreen    ← 整備記録一覧・入力
│   ├── 整備記録リスト（タイムライン）
│   ├── 整備入力ダイアログ
│   └── 法定点検チェックリスト
└── VehicleEditScreen          ← 車両情報の登録・編集
    ├── 基本情報フォーム
    └── 保存・削除
```

## 5. 通知設計

| 通知対象 | 通知タイミング | チャネル |
|---------|-------------|---------|
| 車検満了 | 3ヶ月前、1ヶ月前、2週間前、1週間前 | `vehicle_inspection` |
| 自賠責満了 | 車検と同一タイミング | `vehicle_inspection` |
| 任意保険満了 | 1ヶ月前、2週間前 | `insurance` |
| 自動車税納付 | 5月初旬（納付書到着目安） | `tax` |
| オイル交換目安 | 前回交換から5,000km or 6ヶ月 | `maintenance` |
| 法定12ヶ月点検 | 前回の点検から11ヶ月 | `maintenance` |

## 6. 制約・前提条件

- 個人利用を想定（法人のfleet管理は対象外）
- 車両種別は自家用乗用車・軽自動車（バイクは将来対応）
- 車検周期は自家用乗用車のもの（事業用・貨物は対象外）
- 税額は2026年現在の税率に基づく（将来の税制改正で変動あり）
- 整備記録簿のPDF出力は法的効力を持つ「整備記録簿」の代替ではなく、あくまで管理補助

## 7. 用語定義

| 用語 | 定義 |
|------|------|
| 車検 | 自動車検査登録制度。新車は初回3年、以降2年ごとに受検 |
| 自賠責 | 自動車損害賠償責任保険。対人賠償の強制保険 |
| 法定12ヶ月点検 | 道路運送車両法第48条に基づく1年ごとの定期点検 |
| 法定24ヶ月点検 | 車検時に実施する分解点検 |
| 満タン法 | 給油量÷走行距離で実燃費を算出する方法 |
| ODO | オドメーター（積算走行距離計） |
| TCO | Total Cost of Ownership（総所有コスト） |
