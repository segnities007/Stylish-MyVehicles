# 既存の車両管理アプリ調査

## 1. 日本向けアプリ

### 1.1 MyTOYOTA+（トヨタ）

| 項目 | 内容 |
|------|------|
| 提供元 | トヨタ自動車 |
| プラットフォーム | iOS / Android |
| 料金 | 無料（T-Connect契約で機能拡張） |
| 対象 | トヨタ車・レクサス車オーナー |

**主な機能:**
- 車両状態の遠隔確認（コネクティッドカー対応車種）
- 点検・車検の予約（トヨタディーラー）
- 整備履歴の確認
- 燃費記録・走行レポート
- リモート操作（エアコン、ドアロック等 / 対応車種）
- 緊急通報（ヘルプネット）

**強み:** メーカー純正ならではの車両データ連携、ディーラー予約との統合
**弱み:** トヨタ車専用、コネクティッド非対応車種では機能限定、UIが複雑

## 5. 調査サマリー

### 既存アプリの全体傾向

1. **メーカー純正アプリ**は車両データ連携が強みだが、自社車種専用で汎用性がない
2. **燃費特化アプリ**（e燃費、Fuelly）は燃費記録は充実しているが、総合的な車両管理には不向き
3. **海外の総合管理アプリ**（Car Minder、Drivvo）は機能が包括的だが、日本の制度（車検、自賠責、自動車税）に未対応
4. **日本向けの小規模アプリ**はシンプルすぎるか、UI/UXが古い
5. **税金管理**に対応しているアプリはほぼ皆無
6. **整備記録簿のデジタル化**に対応しているアプリは少ない
7. **データポータビリティ**（エクスポート・移行）が弱いアプリが多い

### 市場のギャップ

- 日本の法的制度（車検・自賠責・自動車税）を包括的に管理できるアプリが少ない
- 燃費記録とメンテナンス管理を両立した日本向けアプリが不足
- 整備記録簿（法定点検記録）をデジタルで管理するアプリがほぼない
- 家族・世帯での車両共有管理に対応したアプリが少ない
- オフラインファーストでプライバシーに配慮したアプリが少ない
