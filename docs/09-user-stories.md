# ユーザーストーリー集 — Stylish MyCars

> 作成日: 2026-07-22
> 参照: [要件定義書](04-requirements.md), [基本設計書](05-basic-design.md)

## ペルソナ定義

| ID | ペルソナ | 説明 |
|----|---------|------|
| P1 | 車を1台持つ一般ユーザー（田中さん・30代） | 車検・税金の期限管理と最低限の記録がしたい。ITリテラシーは普通 |
| P2 | 複数台所有する車好き（鈴木さん・40代） | 車両ごとの詳細な整備履歴・費用を管理したい。車に詳しい |
| P3 | 家族で車を共有する世帯（佐藤家） | 家族で記録を共有・閲覧したい（将来対応） |
| P4 | 車を資産として管理したい人（山本さん・50代） | TCOの把握、売却判断材料が欲しい（将来対応） |

## 1. 初回起動・オンボーディング

### US-001: アプリの使い方を理解したい（P1）

**As a** 車を1台持つ一般ユーザー
**I want to** 初回起動時にアプリの機能と使い方を理解したい
**So that** 迷わずに使い始められる

**受け入れ基準:**
- [ ] 初回起動時にオンボーディング画面が表示される
- [ ] アプリの主要機能（期限管理・給油記録・整備/費用管理）が紹介される
- [ ] スキップボタンで即座に始められる
- [ ] オンボーディング完了後、メイン画面に遷移する
- [ ] 2回目以降の起動ではオンボーディングは表示されない

---

### US-002: 最初の車両を登録したい（P1）

**As a** 車を1台持つ一般ユーザー
**I want to** 初回起動後に自分の車を簡単に登録したい
**So that** すぐに期限管理や記録を始められる

**受け入れ基準:**
- [ ] 車両未登録時に「車両を追加しましょう」という案内が表示される
- [ ] 登録ボタンから車両登録画面に遷移できる
- [ ] メーカー・車種・年式の基本情報だけで登録できる
- [ ] 登録後、ダッシュボードに車両が表示される

---

## 2. 車両情報の登録・管理

### US-003: 車両の詳細情報を登録したい（P2）

**As a** 車に詳しいユーザー
**I want to** 型式・排気量・車両重量・ナンバーなどの詳細情報を登録したい
**So that** 税金の自動計算や車検期限の自動算出が正確に行われる

**受け入れ基準:**
- [ ] メーカー、車種、グレード、年式、型式、ナンバーを登録できる
- [ ] 初度登録年月を日付ピッカーで選択できる
- [ ] 排気量(cc)、車両重量(kg)を数値入力できる
- [ ] 車体色、メモを自由入力できる
- [ ] 車両カテゴリ（乗用車/軽自動車/バイク/自転車/トラック）を選択できる

---

### US-004: 複数台の車両を管理したい（P2）

**As a** 複数台所有する車好き
**I want to** 複数の車両を登録して簡単に切り替えたい
**So that** 全ての車両の状況を一元管理できる

**受け入れ基準:**
- [ ] 車両台数に制限なく登録できる
- [ ] スワイプ（HorizontalPager）で車両を切り替えられる
- [ ] ページインジケーターで現在の車両位置がわかる
- [ ] 最後のページに「車両追加」ページがある
- [ ] 各車両のダッシュボードが独立して表示される

---

### US-005: 車両情報を編集・削除したい（P1）

**As a** 車を1台持つ一般ユーザー
**I want to** 登録した車両情報を後から修正したり、手放した車両を削除したい
**So that** 常に正確な情報を維持できる

**受け入れ基準:**
- [ ] ダッシュボードの編集アイコンから車両編集画面に遷移できる
- [ ] 全項目を編集できる
- [ ] 削除時に確認ダイアログが表示される
- [ ] 削除後、関連する記録（給油・整備・費用）も削除される
- [ ] 編集/削除後、ダッシュボードに自動で戻る

---

### US-006: 車検・保険の期限を設定したい（P1）

**As a** 車を1台持つ一般ユーザー
**I want to** 車検満了日・自賠責・任意保険の期限を設定したい
**So that** 期限が近づいたら通知で知らせてもらえる

**受け入れ基準:**
- [ ] 初度登録年月から車検満了日を自動計算する（初回3年、以降2年）
- [ ] 自賠責保険の満期日を手動設定できる
- [ ] 任意保険の満期日・保険会社・等級を設定できる
- [ ] 車両詳細画面で期限一覧を視覚的に確認できる

---

## 3. ダッシュボード・概要把握

### US-007: 車両の「今」を一目で把握したい（P1）

**As a** 車を1台持つ一般ユーザー
**I want to** アプリを開いた瞬間に車両の現状を把握したい
**So that** 車検や整備の期限を見逃さない

**受け入れ基準:**
- [ ] 車両名・ナンバーがヘッダーに表示される
- [ ] 緊急アラート（期限間近/期限切れ）がカードで強調表示される
- [ ] 月間費用・年間費用・平均燃費・総走行距離の統計グリッドが表示される
- [ ] 次のメンテナンス項目と残り日数が表示される
- [ ] 車検残日数が表示される

---

### US-008: 費用の全体像をグラフで把握したい（P2）

**As a** 車に詳しいユーザー
**I want to** 費用の内訳と推移をグラフで確認したい
**So that** どの項目にいくら使っているか分析できる

**受け入れ基準:**
- [ ] 費用カテゴリ別の円グラフ（燃料/整備/保険/税金/その他）が表示される
- [ ] 月次費用の棒グラフが表示される
- [ ] 燃費推移の折れ線グラフが表示される
- [ ] グラフはデータが2件以上ある場合のみ表示される

---

### US-009: 期限が近い項目を優先的に知りたい（P1）

**As a** 車を1台持つ一般ユーザー
**I want to** 期限が迫っている項目を色分けで優先表示してほしい
**So that** 対応の優先順位が一目でわかる

**受け入れ基準:**
- [ ] 期限切れは赤（error）、期限間近は黄/橙（tertiary）、余裕ありは通常色で表示
- [ ] 期限超過の場合は「期限超過」と明示される
- [ ] 残り日数が数値で表示される

---

## 4. 給油記録・燃費管理

### US-010: 給油を素早く記録したい（P1）

**As a** 車を1台持つ一般ユーザー
**I want to** 給油のたびに素早く記録したい
**So that** 燃費の推移を追える

**受け入れ基準:**
- [ ] FAB（＋ボタン）またはボトムバーから給油記録画面を開ける
- [ ] 日付、走行距離、給油量、金額を入力できる
- [ ] 満タン法のチェックボックスがある
- [ ] 保存後、記録リストに即座に反映される
- [ ] 入力から保存まで3秒以内で完了できる

---

### US-011: 前回値のプリセットで入力を簡素化したい（P1）

**As a** 車を1台持つ一般ユーザー
**I want to** 給油記録の入力時に前回の値が自動で入っていてほしい
**So that** 毎回ゼロから入力する手間が省ける

**受け入れ基準:**
- [ ] 走行距離に前回の値がプリセットされる
- [ ] 給油量に前回の値がプリセットされる
- [ ] 日付は本日がデフォルト

---

### US-012: レシートを撮影して自動入力したい（P1）

**As a** 車を1台持つ一般ユーザー
**I want to** 給油レシートをカメラで撮影して自動で入力したい
**So that** 手入力の手間とミスを減らせる

**受け入れ基準:**
- [ ] 給油入力ダイアログに「レシート読み取り」ボタンがある
- [ ] カメラ撮影とギャラリー選択の両方に対応
- [ ] OCRで給油量・金額・走行距離を自動抽出する
- [ ] 読み取り結果がフォームに自動入力される
- [ ] 読み取り中はスキャン中インジケーターが表示される

---

### US-013: 燃費の推移をグラフで確認したい（P2）

**As a** 車に詳しいユーザー
**I want to** 燃費の経時変化をグラフで確認したい
**So that** 愛車の調子や運転パターンの変化を把握できる

**受け入れ基準:**
- [ ] 給油記録画面に燃費推移の折れ線グラフが表示される
- [ ] 2件以上の燃費データで自動表示される
- [ ] 期間フィルタ（全期間/年/月）で絞り込める
- [ ] 平均燃費がサマリーに表示される

---

### US-014: 給油記録を期間で絞り込みたい（P2）

**As a** 車に詳しいユーザー
**I want to** 給油記録を期間（全期間/年/月）で絞り込みたい
**So that** 特定の期間の燃費や費用を分析できる

**受け入れ基準:**
- [ ] チップ（Chip）で期間を選択できる
- [ ] 選択期間の平均燃費・総給油量・合計費用が表示される
- [ ] 該当期の記録がない場合は空状態メッセージが表示される

---

### US-015: 給油記録を編集・削除したい（P1）

**As a** 車を1台持つ一般ユーザー
**I want to** 間違えた給油記録を修正したり削除したい
**So that** 正確なデータを維持できる

**受け入れ基準:**
- [ ] リスト項目のタップで編集ダイアログが開く
- [ ] 長押しで削除確認ダイアログが表示される
- [ ] 削除は確認後に実行される（誤削除防止）

---

## 5. メンテナンス記録

### US-016: 整備を記録したい（P1）

**As a** 車を1台持つ一般ユーザー
**I want to** オイル交換やタイヤ交換などの整備を記録したい
**So that** 整備履歴を後から確認できる

**受け入れ基準:**
- [ ] FABから整備記録の入力ダイアログを開ける
- [ ] 日付、カテゴリ、内容、費用、走行距離、整備工場、メモを入力できる
- [ ] カテゴリからテンプレート（オイル交換/タイヤ交換/バッテリー等）を選択できる
- [ ] 保存後、記録がリストに反映される

---

### US-017: 整備のテンプレートから選びたい（P1）

**As a** 車を1台持つ一般ユーザー
**I want to** 整備項目をテンプレートから選択したい
**So that** 毎回項目名を手入力しなくて済む

**受け入れ基準:**
- [ ] 車両カテゴリに応じたメンテナンスカテゴリが提示される
- [ ] 乗用車: オイル/オイルフィルタ/タイヤ/バッテリー/ブレーキ/ワイパー/エアフィルタ/冷却水/12ヶ月点検
- [ ] バイク: オイル/オイルフィルタ/チェーン/タイヤ/バッテリー/ブレーキ/スパークプラグ/冷却水
- [ ] 自転車: タイヤ/ブレーキ/チェーン/ギア/全般点検

---

### US-018: 整備履歴を時系列で確認したい（P2）

**As a** 車に詳しいユーザー
**I want to** 整備履歴を時系列で一覧表示したい
**So that** いつ何を整備したか一目でわかる

**受け入れ基準:**
- [ ] 整備記録が日付の新しい順に表示される
- [ ] 各記録に日付・カテゴリ・内容・費用が表示される
- [ ] 期間フィルタで絞り込める

---

### US-019: 次のメンテナンス時期を知りたい（P1）

**As a** 車を1台持つ一般ユーザー
**I want to** 次のオイル交換やタイヤ交換の目安時期を知りたい
**So that** 整備のタイミングを逃さない

**受け入れ基準:**
- [ ] 車両カテゴリ別のメンテナンススケジュールが自動生成される
- [ ] 期間ベース（ヶ月）と距離ベース（km）の両方で管理できる
- [ ] ダッシュボードに次のメンテナンス項目と残り日数が表示される
- [ ] 車両詳細画面でスケジュール一覧を編集できる

---

### US-020: メンテナンススケジュールをカスタマイズしたい（P2）

**As a** 車に詳しいユーザー
**I want to** 整備サイクル（km/月）を自分の基準に変更したい
**So that** 自分のメンテナンス方針に合った通知を受けられる

**受け入れ基準:**
- [ ] 車両詳細画面のメンテナンススケジュールセクションから編集できる
- [ ] 間隔（km/月）と最終実施日/走行距離を変更できる
- [ ] 変更後、次回期限が再計算される

---

- [ ] 日付、タイトル、金額、メモを入力できる
- [ ] 給油記録・整備記録から自動的に費用記録が作成される

---

### US-022: 月次・年次の費用集計を見たい（P2）

**As a** 車に詳しいユーザー
**I want to** 月次・年次の費用集計を確認したい
**So that** 年間の維持費を把握できる

**受け入れ基準:**

---

### US-023: 給油・整備から自動で費用記録したい（P1）

- [ ] 費用画面に統合して表示される

## 7. 通知・リマインダー

### US-024: 車検・保険の期限を通知で知りたい（P1）

**As a** 車を1台持つ一般ユーザー
**I want to** 車検・自賠責・任意保険の期限が近づいたら通知で知らせてほしい
**So that** 期限切れによる法的リスクを避けられる

**受け入れ基準:**
- [ ] 車検: 90日前、30日前、14日前、7日前に通知
- [ ] 自賠責: 30日前、14日前、7日前に通知
- [ ] 任意保険: 30日前、14日前に通知
- [ ] 期限切れの場合は超過通知
- [ ] Android通知として配信される（WorkManager）

---

### US-025: メンテナンス時期を通知で知りたい（P1）

**As a** 車を1台持つ一般ユーザー
**I want to** オイル交換などのメンテナンス時期を通知で知りたい
**So that** 整備のタイミングを逃さない

**受け入れ基準:**
- [ ] 期間ベース: 期限7日前から通知
- [ ] 距離ベース: 残り500km以下で通知
- [ ] 期限超過の場合も通知
- [ ] 通知に車両名とメンテナンス項目が含まれる

---

### US-026: 自動車税の納付時期を知りたい（P1）

**As a** 車を1台持つ一般ユーザー
**I want to** 自動車税の納付時期に通知を受けたい
**So that** 納付忘れによる延滞金を避けられる

**受け入れ基準:**
- [ ] 5月初旬（1日〜7日）に納付通知
- [ ] 当年に税金の費用記録がある場合は通知しない
- [ ] 通知に車両名が含まれる

---

### US-027: アプリ内で期限一覧を確認したい（P1）

**As a** 車を1台持つ一般ユーザー
**I want to** 全車両の期限情報をアプリ内で一覧確認したい
**So that** 通知を見逃してもアプリで確認できる

**受け入れ基準:**
- [ ] 通知画面に全車両の期限情報が表示される
- [ ] 「期限切れ」「まもなく期限」「今後の予定」の3セクションで分類
- [ ] 各項目に車両名・項目名・日付・残り日数が表示される
- [ ] 期限切れは赤、期限間近は強調色で表示
- [ ] 通知がない場合は空状態メッセージ

---

## 8. データ管理・エクスポート

### US-028: データをCSVでエクスポートしたい（P2）

**As a** 車に詳しいユーザー
**I want to** 車両情報・給油記録・整備記録・費用記録をCSVで出力したい
**So that** バックアップや他アプリへの移行ができる

**受け入れ基準:**
- [ ] 車両詳細画面からエクスポートを実行できる
- [ ] 車両情報CSV、給油記録CSV、整備記録CSV、費用記録CSVを出力できる
- [ ] ヘッダー行付きのUTF-8 CSV
- [ ] システムの共有シート（SAF）で保存先を選択できる

---

### US-029: データをオフラインで使いたい（P1）

**As a** 車を1台持つ一般ユーザー
**I want to** ネットワーク接続なしで全ての機能を使いたい
**So that** 地下駐車場や圏外でも記録できる

**受け入れ基準:**
- [ ] 全データがローカルDB（Room）に保存される
- [ ] ネットワーク接続を一切必要としない
- [ ] アプリ起動から記録まで完全にオフラインで動作する

---

## 10. 複数車両の横断管理（P2）

### US-032: 全車両の記録をまとめて見たい（P2）
