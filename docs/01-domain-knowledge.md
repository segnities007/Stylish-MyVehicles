# 車両管理のドメイン知識

## 1. 法的・制度的要件（日本）

### 1.1 車検（自動車検査登録制度）

| 項目 | 内容 |
|------|------|
| 対象 | 登録から3年経過した自家用乗用車（以降2年ごと） |
| 初回 | 新車登録から3年後 |
| 2回目以降 | 2年ごと |
| 費用目安 | 法定費用（重量税+自賠責+印紙代）: 約5〜7万円 / 整備費用: 3〜10万円（依頼先による） |
| 手続き | 運輸支局で受検、または整備工場に代行依頼 |
| 必要書類 | 自動車検査証、自賠責保険証明書、自動車税納税証明書、点検整備記録簿 |

**アプリでの管理ポイント:**
- 車検満了日のリマインダー（3ヶ月前、1ヶ月前、2週間前など段階的通知）
- 車検費用の記録と比較
- 必要書類のチェックリスト
- 車検業者の比較メモ

### 1.2 自賠責保険（自動車損害賠償責任保険）

| 項目 | 内容 |
|------|------|
| 加入 | 強制（未加入での運行は違法） |
| 契約期間 | 通常は車検期間と同一（初回37ヶ月、以降25ヶ月） |
| 費用目安 | 自家用乗用車: 25ヶ月で約17,650円（2023年度以降） |
| 補償範囲 | 対人賠償のみ（対物・車両は対象外） |
| 更新 | 車検時に同時更新が一般的 |

### 1.3 任意保険（自動車保険）

| 項目 | 内容 |
|------|------|
| 加入 | 任意（ただし実質的にほぼ必須） |
| 契約期間 | 通常1年 |
| 費用目安 | 年間3〜15万円（年齢、等級、車種、補償内容による） |
| 主な補償 | 対人・対物賠償、車両保険、人身傷害、搭乗者傷害 |
| 等級制度 | 1〜20等級（無事故で毎年1等級UP、事故でDOWN） |

**アプリでの管理ポイント:**
- 保険満期日のリマインダー
- 等級の記録（翌年の保険料見積もりに有用）
- 補償内容のメモ・証券写真の保管
- 事故時の連絡先（保険会社、ロードサービス）

### 1.4 自動車税

#### 自動車税種別割（都道府県税）

| 排気量 | 年額（2019年10月以降登録） |
|--------|--------------------------|
| 1,000cc以下 | 25,000円 |
| 1,000cc超〜1,500cc以下 | 30,500円 |
| 1,500cc超〜2,000cc以下 | 36,000円 |
| 2,000cc超〜2,500cc以下 | 43,500円 |
| 2,500cc超〜3,000cc以下 | 50,000円 |
| 3,000cc超〜3,500cc以下 | 57,000円 |
| 3,500cc超〜4,000cc以下 | 65,500円 |
| 4,000cc超〜4,500cc以下 | 75,500円 |
| 4,500cc超〜6,000cc以下 | 87,000円 |
| 6,000cc超 | 110,000円 |

- 納付時期: 毎年5月（4月1日時点の所有者に課税）
- グリーン化特例: 新車登録から13年超で約15%加算

#### 自動車重量税（国税）

| 車両重量 | 2年分（エコカー以外） |
|----------|---------------------|
| 500kg以下 | 8,200円 |
| 500kg超〜1,000kg以下 | 16,400円 |
| 1,000kg超〜1,500kg以下 | 24,600円 |
| 1,500kg超〜2,000kg以下 | 32,800円 |
| 2,000kg超〜2,500kg以下 | 41,000円 |

- 車検時にまとめて納付

### 1.5 リサイクル券（自動車リサイクル法）

| 項目 | 内容 |
|------|------|
| 費用 | 6,000〜18,000円程度（車種による） |
| 支払い | 新車購入時または初回車検時に一括 |
| 内容 | シュレッダーダスト、エアバッグ類、フロン類の回収・処理費用 |
| 管理 | リサイクル券番号を保管（廃車時に必要） |

### 1.6 車庫証明（自動車保管場所証明書）

- 新車登録・名義変更・住所変更時に必要
- 保管場所（駐車場）の所在地を管轄する警察署で申請
- 費用: 約2,500〜3,000円（申請手数料+標章交付手数料）

### 1.7 登録・名義変更

- 新車登録: ディーラーが代行（費用約3〜5万円）
- 中古車購入時: 名義変更が必要
- 住所変更: 転居時に手続き必要
- 相続: 所有者死亡時に名義変更

| オイルフィルター | オイル交換2回に1回 | 1,000〜3,000円 | |

### 2.2 法定点検

| 点検 | 周期 | 内容 | 費用目安 |
|------|------|------|---------|
| 12ヶ月点検 | 1年ごと | 26項目（エンジン、ブレーキ、足回り等） | 1〜2万円 |
| 24ヶ月点検 | 2年ごと（車検時） | 56項目（12ヶ月点検+分解点検） | 3〜5万円 |

- 法定点検は義務（道路運送車両法第47条、48条）
- 点検記録簿の保存が推奨される（整備履歴の証明）

### 2.3 日常点検（ユーザー自身）

- 15日点検（推奨）: エンジンオイル量、冷却水量、バッテリー液、タイヤ空気圧、灯火装置等
- 運行前点検: ブレーキ、タイヤ、灯火、ワイパー等

## 3. 車両コスト管理

### 3.1 年間維持費の構成（一般的な例: 1,500ccコンパクトカー）

| 費目 | 年間費用目安 | 備考 |
|------|------------|------|
| 自動車税（種別割） | 30,500円 | 排気量による |
| 自動車重量税 | 約12,300円/年 | 車検時に2年分 |
| 自賠責保険 | 約8,500円/年 | 車検時に一括 |
| 任意保険 | 5〜10万円 | 条件による |
| 車検費用（整備） | 約3〜5万円/年 | 2年に1回を按分 |
| 燃料費 | 10〜15万円 | 走行距離・燃費による |
| メンテナンス | 3〜10万円 | |
| 駐車場代 | 0〜20万円 | 地域による |
| **合計** | **約30〜70万円/年** | |

### 3.2 燃費管理

- 満タン法: 給油量 ÷ 走行距離 = 実燃費
- 記録項目: 日付、給油量(L)、金額、単価、走行距離、燃費(km/L)
- 燃費の推移で車両の状態を把握可能（燃費悪化 = 何らかの不調の兆候）

### 3.3 走行距離管理

- 年間走行距離の目安: 8,000〜12,000km
- 走行距離は車両の価値に直結
- メンテナンス周期の基準

## 4. 車両の基本情報

### 4.1 管理すべき車両情報

| カテゴリ | 項目 |
|---------|------|
| 基本情報 | メーカー、車種、グレード、年式、型式、ボディカラー |
| 識別情報 | 車体番号（VIN/フレーム番号）、ナンバープレート番号 |
| 仕様 | 排気量、駆動方式（FF/FR/4WD等）、ミッション（AT/MT/CVT） |
| 購入情報 | 購入日、購入先、購入価格、新車/中古車 |
| 保証 | 保証期間、保証内容、延長保証 |
| 登録情報 | 初度登録年月、車検満了日、登録番号 |
| 保険 | 自賠責満了日、任意保険の証券番号・満期日 |
| タイヤ | サイズ、銘柄、交換日・走行距離 |
| バッテリー | 型式、交換日 |

### 4.2 車体番号（VIN）

- 17桁の英数字（国際標準ISO 3779）
- 車両の製造国、メーカー、車種、年式、製造番号を编码
- 車検証、運転席ドア付近、エンジンルーム等で確認可能

## 5. 車両のライフサイクル

### 5.1 購入フェーズ

- **新車**: ディーラーで見積もり→契約→登録→納車（1〜3ヶ月）
- **中古車**: 車両探し→現車確認→契約→名義変更→納車
- 記録すべき情報: 購入価格、諸費用、オプション、保証内容、納車日

### 5.2 使用・維持フェーズ

- 日常の給油・走行記録
- 定期メンテナンスの実施と記録
- 車検・保険・税金の期限管理
- 故障・修理の記録

### 5.3 売却・廃車フェーズ

- **売却**: 査定→買取業者選定→名義変更→入金
- **下取り**: 新車購入時にディーラーに下取り
- **廃車**: 抹消登録→解体→リサイクル券使用
- 記録: 売却価格、売却日、走行距離、状態

### 5.4 車両の資産価値

- 新車購入後、年々価値は下落
- 一般的な下落: 1年で約20〜30%、3年で約40〜50%、5年で約60〜70%
- 走行距離、事故歴、人気車種かで変動
- 残価の把握は買い替え判断に有用

## 6. 複数台管理のユースケース

### 6.1 世帯での複数台所有

- 日本では地方を中心に1世帯2台以上が一般的
- 家族それぞれが車両を管理、または世帯主が一元管理
- 共有車両と個人車両の混在

### 6.2 趣味の車（複数台）

- メインカー + セカンドカー（スポーツカー、旧車等）
- 使用頻度が異なるため、メンテナンス周期が走行距離ベースだけでなく時間ベースでも重要
- 保管状態の管理（バッテリー上がり、タイヤのフラットスポット等）

### 6.3 法人・事業用

- 社用車の fleet 管理
- 運行記録（運行管理日報）
- 経費管理（燃料費、メンテナンス費の経費計上）
- 複数ドライバー

## 7. ドメイン用語集

| 用語 | 意味 |
|------|------|
| 車検 | 自動車検査登録制度。車両が保安基準に適合しているか検査 |
| 自賠責 | 自動車損害賠償責任保険。対人賠償の強制保険 |
| 法定点検 | 道路運送車両法で定められた定期点検（12ヶ月/24ヶ月） |
| 整備記録簿 | 点検・整備の内容を記録する書類（法定保存） |
| 車庫証明 | 自動車の保管場所を証明する書類 |
| リサイクル券 | 自動車リサイクル法に基づく預託金の証明書 |
| グリーン化特例 | 環境負荷の大きい古い車に自動車税を加算する制度 |
| 残価 | 将来の予想売却価格（残価設定ローンの基準にもなる） |
| OBD-II | 車両診断コネクタの規格。故障コードの読み取り等が可能 |
| VIN | Vehicle Identification Number（車台番号） |
| ODO | オドメーター（積算走行距離計） |
| 満タン法 | 給油量と走行距離から実燃費を算出する方法 |
